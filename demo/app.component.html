A REAL-WORLD EXAMPLE, STEP BY STEP

Build a
scientific calculator.

Beyond simple addition: parse powers, functions, constants, and scientific notation, from the first character to the result.

01↗

Define the tokens

The lexer turns text into pieces such as NUMBER, IDENT, and PLUS.

NUMBER = "0".."9", {{ '{' }} "0".."9" {{ '}' }};
02↗

Describe the syntax

The grammar combines tokens and defines the order of operations, from parentheses to powers.

power = primary, POWER, unary;
03↗

Add meaning

Semantic actions evaluate each reduction and apply functions such as sqrt and sin.

args => args[0].rules ** args[2].rules
04↗

Generate and run

Generate the tables, connect the lexer to the parser, and evaluate the expression with parse().

parser.parse('sqrt(81)'); // 9

BEYOND THE CALCULATOR

A small core.
Big possibilities.

The same approach works for configuration languages, DSLs, code analyzers, and other applications.

01 / ALGORITHMS

Choose your parser.

Use SLR(1), LALR(1), LR(1), or GLR. GLR can preserve multiple derivations.

02 / STREAMING

One piece at a time.

Use start(), push(), and finish() to process input incrementally.

03 / DIAGNOSTICS

Errors that help.
